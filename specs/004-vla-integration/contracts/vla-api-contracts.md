# VLA API Contracts

## Overview

This document defines the API contracts for the Vision-Language-Action (VLA) system, specifying the interfaces between speech recognition, LLM planning, and action execution components.

## Message Definitions

### VLA Command Message

**Topic**: `/vla/command`

**Message Type**: `simulation.vla.VLACommand`

**Description**: Message containing voice command processed by speech recognition

```
string command_text
float32 confidence_score
string intent
string[] parameters
time timestamp
```

**Example**:
```json
{
  "command_text": "go to the kitchen",
  "confidence_score": 0.92,
  "intent": "NAVIGATE_TO_LOCATION",
  "parameters": ["kitchen"],
  "timestamp": "2025-12-16T10:30:00Z"
}
```

### VLA Action Sequence Message

**Topic**: `/vla/action_sequence`

**Message Type**: `simulation.vla.VLAActionSequence`

**Description**: Message containing planned sequence of actions generated by LLM

```
VLAAction[] actions
string status
duration estimated_duration
string safety_level
```

**Example**:
```json
{
  "actions": [
    {
      "action_type": "NAVIGATION",
      "action_parameters": ["location=kitchen"],
      "priority": 1,
      "timeout": 30.0,
      "dependencies": []
    }
  ],
  "status": "PENDING",
  "estimated_duration": 45.0,
  "safety_level": "NORMAL"
}
```

### VLA Action Message

**Topic**: `/vla/action`

**Message Type**: `simulation.vla.VLAAction`

**Description**: Individual action within a sequence

```
string action_type
string[] action_parameters
int8 priority  # 0=LOW, 1=MEDIUM, 2=HIGH
duration timeout
string[] dependencies
```

### VLA Status Message

**Topic**: `/vla/status`

**Message Type**: `simulation.vla.VLAStatus`

**Description**: Status updates for VLA pipeline execution

```
string current_state
string current_action
float32 progress_percentage
string[] recent_actions
string error_message
```

**Example**:
```json
{
  "current_state": "EXECUTING",
  "current_action": "NAVIGATING_TO_LOCATION",
  "progress_percentage": 65.0,
  "recent_actions": ["RECEIVED_COMMAND", "GENERATED_PLAN"],
  "error_message": ""
}
```

## Service Definitions

### Command Processing Service

**Service Type**: `simulation.vla.ProcessCommand`

**Request**:
```
string raw_command
float32 audio_confidence
```

**Response**:
```
bool success
string processed_command
string intent
string[] parameters
string error_message
```

**Example Request**:
```json
{
  "raw_command": "pick up the red cup",
  "audio_confidence": 0.89
}
```

**Example Response**:
```json
{
  "success": true,
  "processed_command": "pick up the red cup",
  "intent": "PICK_UP_OBJECT",
  "parameters": ["red cup"],
  "error_message": ""
}
```

### Action Planning Service

**Service Type**: `simulation.vla.PlanActions`

**Request**:
```
string command_text
string intent
string[] parameters
```

**Response**:
```
bool success
VLAActionSequence action_sequence
string error_message
```

### Safety Validation Service

**Service Type**: `simulation.vla.ValidateSafety`

**Request**:
```
VLAActionSequence action_sequence
```

**Response**:
```
bool is_safe
bool requires_confirmation
string[] safety_issues
string error_message
```

## Action Types

### Navigation Actions

- `NAVIGATE_TO_LOCATION`: Navigate to a specific location
  - Parameters: `location`, `frame_id`
  - Example: `{"location": "kitchen", "frame_id": "map"}`

- `NAVIGATE_TO_OBJECT`: Navigate to a detected object
  - Parameters: `object_id`, `approach_distance`
  - Example: `{"object_id": "red_cup_001", "approach_distance": "0.5"}`

### Perception Actions

- `DETECT_OBJECTS`: Detect objects in the environment
  - Parameters: `object_types`, `detection_range`
  - Example: `{"object_types": ["cup", "ball"], "detection_range": "2.0"}`

- `LOCALIZE_OBJECT`: Get precise location of a specific object
  - Parameters: `object_type`, `search_area`
  - Example: `{"object_type": "red_cup", "search_area": "table"}`

### Manipulation Actions

- `GRASP_OBJECT`: Grasp a specific object
  - Parameters: `object_id`, `grasp_type`
  - Example: `{"object_id": "red_cup_001", "grasp_type": "top_grasp"}`

- `PLACE_OBJECT`: Place an object at a location
  - Parameters: `object_id`, `target_location`, `placement_type`
  - Example: `{"object_id": "red_cup_001", "target_location": "table", "placement_type": "center"}`

### System Actions

- `WAIT`: Pause execution for a duration
  - Parameters: `duration`
  - Example: `{"duration": "5.0"}`

- `SPEAK`: Generate speech output
  - Parameters: `text`, `voice_type`
  - Example: `{"text": "Task completed", "voice_type": "neutral"}`

## Quality of Service (QoS) Settings

### Topics

- `/vla/command`: `reliable`, `keep_last(10)`
- `/vla/action_sequence`: `reliable`, `keep_last(5)`
- `/vla/status`: `best_effort`, `keep_last(10)`

### Services

- All services: `reliable`, `timeout(30s)`

## Error Handling

### Standard Error Codes

- `0`: Success
- `1`: General error
- `2`: Invalid input
- `3`: Timeout
- `4`: Safety violation
- `5`: Resource unavailable

### Error Response Format

All services return errors in the format:
```json
{
  "success": false,
  "error_code": 2,
  "error_message": "Invalid command format"
}
```

## Validation Rules

### Command Text Validation
- Must be non-empty
- Maximum length: 200 characters
- Must contain recognizable intent

### Action Sequence Validation
- Must contain at least one action
- All actions must have valid types
- Dependencies must form acyclic graph
- Total estimated duration must be reasonable

### Safety Validation
- All navigation targets must exist in map
- Manipulation objects must be accessible
- No actions that could harm robot or environment
